# TikTok Studio

Небольшая студия, которая делает из вашего текста готовое вертикальное видео для TikTok: с нейро-озвучкой, субтитрами в стиле TikTok (текущее слово подсвечивается), фоном и музыкой.

Пишете текст → выбираете голос и стиль → нажимаете **«Создать видео»** → получаете MP4 1080×1920, который сразу можно загружать в TikTok (а также в Reels и Shorts).

## Что умеет

- **Озвучка** нейроголосами Microsoft Edge: бесплатно и без ключей. Русские голоса (Дмитрий, Светлана), украинские, казахские, английские, а также «мультиязычные» голоса, которые тоже читают по-русски. Можно менять скорость и тон и прослушать голос до рендера.
- **Субтитры по словам**: тайминг каждого слова берётся от синтезатора, поэтому подсветка точно совпадает с речью. Фразы по 1–6 слов, переносы и паузы учитываются автоматически.
  - 5 готовых стилей (Классика, Неон, Розовый, Плашка, Минимал) и ручная настройка: шрифт, размер, цвета, обводка, плашка, положение, ЗАГЛАВНЫЕ, анимация появления.
  - 5 жирных шрифтов с кириллицей уже в комплекте: Montserrat, Rubik, Oswald, Russo One.
- **Заголовок-хук** вверху кадра: на весь ролик или на первые N секунд.
- **Фон** на выбор:
  - анимированный градиент (7 пресетов или свои цвета);
  - ваши фото и видео: кадры меняются на границах предложений или абзацев, фото плавно «едут» (эффект Кена Бёрнса), между сценами идут переходы, горизонтальные кадры можно вписать целиком на размытую подложку;
  - **ИИ-картинки** по вашему тексту: студия делит текст на сцены, нейросеть придумывает и рисует кадр под каждую фразу, а для отдельных сцен может сделать и ИИ-видео;
  - бесплатные стоковые видео с Pexels по ключевым словам.
- **Фоновая музыка**: зацикливается, плавно затихает в конце, громкость настраивается.
- **Превью** в рамке телефона, которое меняется сразу при правке настроек, и режим показа зон интерфейса TikTok (чтобы текст не оказался под кнопками).
- **Библиотека роликов**: все готовые видео, скачивание, файл субтитров `.srt`, повторная загрузка текста и настроек любого ролика.
- Громкость голоса нормализуется до −14 LUFS (рекомендация TikTok); видео кодируется в H.264 + AAC, 30 кадров/с.
- Черновик (текст и настройки) сохраняется в браузере автоматически.

## Установка и запуск

Нужен **Python 3.10 или новее**. ffmpeg ставить не обязательно: если его нет в системе, будет использована сборка из пакета `imageio-ffmpeg`.

### Windows

1. Установите Python с [python.org](https://www.python.org/downloads/) и при установке отметьте **«Add python.exe to PATH»**.
2. Скачайте этот репозиторий (кнопка **Code → Download ZIP**) и распакуйте.
3. Дважды щёлкните **`start.bat`**. Первый запуск займёт пару минут: программа сама создаст окружение и установит зависимости.
4. Студия откроется в браузере по адресу <http://127.0.0.1:8765>.

### macOS / Linux

```bash
./start.sh
```

### Вручную

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate    macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
python run.py            # параметры: --port 8765, --no-browser
# или одной командой: python launcher.py — сам создаст окружение и поставит зависимости
```

## С телефона

Студию можно открывать с телефона и делать видео прямо с него: писать текст, загружать фото и видео из галереи, скачивать готовый ролик. Сама студия при этом работает на компьютере (видео собирается на нём), а телефон служит пультом — поэтому компьютер должен быть включён.

### Через интернет (мобильная сеть или любой Wi-Fi)

1. Запустите студию как обычно (`start.bat`) и нажмите кнопку **📱** вверху.
2. Нажмите **«Включить доступ из интернета»**. В первый раз студия скачает программу cloudflared (~40 МБ) от Cloudflare.
3. Через 5–15 секунд появится QR-код со ссылкой вида `https://….trycloudflare.com`. Отсканируйте его телефоном — подойдёт любой интернет.

Если провайдер режет один из способов подключения к Cloudflare (часто это QUIC/UDP), студия сама попробует другие: обычный TCP, QUIC и запасные серверы Cloudflare.

Особенности: ссылка временная и меняется при каждом включении (после перезапуска студии отсканируйте QR заново); через интернет можно загрузить файл до 100 МБ; аккаунт Cloudflare не нужен. Если ссылка не открывается на мобильном интернете (бывает, что оператор ограничивает Cloudflare), включите на телефоне VPN или используйте [Tailscale](https://tailscale.com): поставьте его на компьютер и телефон под одним аккаунтом, запустите студию через `start-phone.bat` — адрес Tailscale появится в окне 📱 в разделе «Через домашний Wi-Fi» и будет работать откуда угодно.

### Через домашний Wi-Fi

1. Запустите студию через **`start-phone.bat`** (на macOS/Linux: `./start.sh --phone`).
2. Если Windows спросит про брандмауэр, отметьте **«Частные сети»** и нажмите **«Разрешить доступ»**.
3. Нажмите **📱** и отсканируйте QR-код телефоном, подключённым к той же сети Wi-Fi.

Если телефон не подключается, проверьте, что в параметрах Windows ваша сеть Wi-Fi отмечена как **«Частная»**.

### Общее

- Без кода доступа (он есть в QR-коде и в окне 📱) никто другой студию не откроет; после 30 неверных попыток вход закрывается на 10 минут. Телефон запоминает вход — код вводится один раз.
- Чтобы студия была под рукой, добавьте её на главный экран: Safari — «Поделиться → На экран Домой», Chrome — «⋮ → Добавить на главный экран».

## Как сделать ролик

1. Вставьте текст. Пустая строка между абзацами означает новую сцену (это важно, если фон меняется по абзацам).
2. При желании добавьте заголовок-хук, например «3 факта, о которых молчат».
3. **Голос**: выберите язык и голос, нажмите «Прослушать».
4. **Субтитры**: выберите стиль или настройте его вручную. Включите «Зоны интерфейса TikTok» в превью и проверьте, что текст не попадает под кнопки.
5. **Фон**: градиент, свои файлы (перетащите их в окно) или стоки Pexels.
6. **Музыка** (необязательно): загрузите трек и выставьте громкость 10–20%.
7. Нажмите **«Создать видео»** (или Ctrl+Enter), дождитесь окончания и скачайте MP4.

Советы:
- Оптимальная длина ролика 20–60 секунд, это примерно 300–800 символов текста.
- Первая фраза должна цеплять: зритель решает за 1–2 секунды.
- В TikTok при публикации включите отметку **«Контент, созданный ИИ»**: в ролике синтезированный голос.
- Используйте только ту музыку и те видео, на которые у вас есть права.

## ИИ-картинки и видео по тексту

На вкладке **Фон → ИИ-картинки** студия сама подбирает кадры под текст:

1. Текст делится на сцены по 3–6 секунд озвучки (по предложениям; абзац — всегда новая сцена).
2. Языковая модель пишет для каждой сцены описание кадра на английском, чтобы герои и обстановка совпадали от сцены к сцене. Подсказать нейросети, о чём ролик, можно в поле «О чём ролик», например: «реклама Telegram-бота, который сохраняет удалённые сообщения».
3. Нейросеть-художник рисует картинку в выбранном стиле (реалистичное фото, кино, неон, 3D-мультфильм, аниме, иллюстрация).
4. В видео каждая картинка появляется ровно на своей фразе и плавно движется.

Можно ничего не настраивать и сразу нажать «Создать видео»: сцены и картинки появятся сами. А можно сначала нажать «Придумать кадры», поправить описания и перерисовать неудачные картинки. Нарисованные кадры сохраняются, при повторном рендере заново рисуются только сцены, текст которых изменился.

### Подключение нейросети

Откройте ⚙ **Настройки → Нейросети для картинок и видео** и выберите сервис:

| Сервис | Что умеет | Цена | Как подключить |
|---|---|---|---|
| **Cloudflare Workers AI** | картинки (FLUX.1 schnell или SDXL Lightning) | бесплатно, 10 000 «нейронов» в сутки — это десятки картинок | Зарегистрируйтесь на [cloudflare.com](https://dash.cloudflare.com/sign-up) (без карты) → **AI → Workers AI → Use REST API** → скопируйте **Account ID** и создайте **API-токен** |
| **Pollinations** | картинки и **видео** (Veo, Seedance, Wan и др.) | платно: ≈ 1 Pollen за $1, картинка стоит доли цента, видео дороже | Создайте ключ на [enter.pollinations.ai](https://enter.pollinations.ai) и пополните баланс |

ИИ-видео делается по кнопке «🎬 Сделать видео» у конкретной сцены, оно платное и занимает 1–5 минут. Автоматически при рендере рисуются только картинки.

## Стоки Pexels

1. Получите бесплатный ключ на <https://www.pexels.com/api/>.
2. Откройте ⚙ **Настройки** в студии и вставьте ключ.
3. На вкладке **Фон → Стоки Pexels** перечислите ключевые слова через запятую (`ночной город, океан, кофе`): на каждое слово скачается один вертикальный клип. Скачанные клипы кэшируются.

## Командная строка

Без браузера, например для пакетной генерации:

```bash
python -m studio.cli script.txt -o video.mp4
python -m studio.cli script.txt --voice ru-RU-SvetlanaNeural --rate 10 --title "Почему так?" \
       --media фото1.jpg клип.mp4 --music трек.mp3 --music-volume 0.15
python -m studio.cli script.txt --pexels "космос, звёзды"
python -m studio.cli --list-voices ru     # список голосов
python -m studio.cli --help               # все параметры
```

## Если что-то не работает

| Проблема | Что делать |
|---|---|
| «Не удалось получить озвучку от Microsoft Edge TTS» | Нужен интернет. Если сервис Microsoft недоступен из вашей сети, укажите прокси в ⚙ Настройках или включите VPN. На Windows есть офлайн-запасной вариант: в списке «Язык» выберите «Системные (без интернета)»; качество там ниже, а тайминг слов оценивается приблизительно. |
| При запуске `start.bat`: «Не удалось подготовить Python» | Обычно мешает кириллица в пути к папке или антивирус. Студия сама пробует запасную папку `C:\ProgramData\TikTokStudio`; если не помогло — перенесите папку студии, например, в `D:\TikTokStudio` и запустите снова. В окне будет показана точная причина. |
| Значок «ffmpeg не найден» или «ffmpeg неполный» | Установите полный ffmpeg: Windows `winget install Gyan.FFmpeg`, macOS `brew install ffmpeg`, Ubuntu `sudo apt install ffmpeg`, затем перезапустите студию. Можно указать путь вручную через переменную `TIKTOK_STUDIO_FFMPEG`. |
| Рендер долгий | На вкладке «Экспорт» выберите качество «Быстро». Больше всего времени занимают длинные ролики с большим количеством фото (эффект движения камеры). |
| Ошибка рендера | Причина показана в блоке прогресса; полный журнал — по кнопке «Подробности». |
| «Закончился бесплатный дневной лимит Cloudflare» | Лимит обновляется в 03:00 по Москве. Уже нарисованные картинки можно использовать — они сохранены. |
| Нейросеть рисует текст или логотипы на картинке | Уберите из описания кадра слова про надписи и экран с текстом, нажмите «Перерисовать». |

## Где хранятся файлы

Всё лежит в папке `workspace/` рядом с программой:
- `outputs/`: готовые видео (`.mp4`), субтитры (`.srt`), превью и настройки каждого ролика;
- `uploads/`: загруженные фото, видео и музыка;
- `cache/`: кэш голосов, прослушиваний и клипов Pexels;
- `settings.json`: ключи Pexels и нейросетей, прокси. Нарисованные нейросетью картинки лежат в `uploads/` вместе с вашими файлами.

Другую папку можно задать переменной окружения `TIKTOK_STUDIO_WORKSPACE`.

## Для разработчиков

```
launcher.py            подготовка окружения и запуск (его вызывают start.bat, start-phone.bat и start.sh)
run.py                 запуск веб-сервера
studio/
  server.py            HTTP API (FastAPI) и раздача интерфейса
  pipeline.py          сборка ролика: озвучка → тайминги → субтитры → фон → MP4
  tts.py               озвучка (edge-tts, офлайн pyttsx3), список голосов
  timing.py            сопоставление меток слов с текстом, оценка таймингов по паузам
  subtitles.py         разбивка на фразы, перенос строк, генерация ASS/SRT
  backgrounds.py       градиенты, нарезка медиа по сценам, графы фильтров ffmpeg
  pexels.py            поиск и скачивание стоковых видео
  ai.py                сцены, промты и генерация картинок/видео (Cloudflare, Pollinations)
  net.py               HTTP-запросы к внешним сервисам
  phone.py             вход с телефона: код доступа, адреса в сети, QR-код
  tunnel.py            доступ из интернета через туннель Cloudflare (cloudflared)
  library.py           загруженные файлы и готовые ролики
  jobs.py              очередь рендера в фоновом потоке
  project.py           параметры ролика по умолчанию и их проверка
  cli.py               командная строка
  web/                 интерфейс (HTML/CSS/JS без сборки)
  assets/fonts/        шрифты (SIL Open Font License, тексты лицензий рядом)
tests/                 pytest; рендер проверяется с имитацией голоса
```

Тесты: `pip install pytest && python -m pytest`.

Озвучка работает через неофициальный клиент [edge-tts](https://github.com/rany2/edge-tts) к онлайн-сервису Microsoft Edge «Читать вслух». Если вы используете ролики в коммерческих целях, проверьте условия использования сервиса.
