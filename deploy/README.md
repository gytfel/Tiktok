# TikTok Studio на сервере

Студию можно поставить на арендованный сервер (VPS). Тогда она работает круглосуточно, компьютер не нужен: открываете ссылку на телефоне с любым интернетом и делаете видео. Видео собирается на сервере, готовый ролик скачивается на телефон.

Установка — одна команда, займёт 5–10 минут.

## 1. Арендуйте сервер

Подойдёт обычный VPS (например, Timeweb Cloud, Aeza, VDSina). При заказе выберите:

- **Система:** Ubuntu 24.04 (подойдут также Ubuntu 22.04 и Debian 12).
- **Мощность:** от 2 ядер, 2–4 ГБ памяти, диск от 20 ГБ. Чем больше ядер, тем быстрее собирается ролик.
- **Расположение:** Нидерланды, Германия, Финляндия или Казахстан — оттуда стабильнее работают озвучка Microsoft и нейросети.
- **Если вы в России**, берите сервер у российского провайдера, но с расположением за границей. Адреса Cloudflare и крупных зарубежных хостингов (DigitalOcean, Hetzner и т.п.) многие российские операторы замедляют, и студия на таком сервере может плохо открываться с телефона.
- **Публичный IPv4-адрес** (обычно выдаётся по умолчанию).

После создания сервера провайдер покажет его **IP-адрес** и **пароль root** (в панели или в письме).

Если в панели провайдера есть файрвол (раздел «Файрвол», «Сетевые правила», «Security groups»), откройте в нём входящие порты **TCP 22, 80 и 443**.

## 2. Подключитесь к серверу

**С компьютера на Windows:** нажмите `Win + X` → «Терминал» (или «Windows PowerShell») и введите, подставив свой IP:

```
ssh root@123.45.67.89
```

На вопрос `Are you sure you want to continue connecting` напишите `yes` и нажмите Enter. Затем вставьте пароль правой кнопкой мыши и нажмите Enter — символы пароля при вводе не отображаются, это нормально.

**Без компьютера:** у большинства провайдеров есть веб-консоль прямо в панели управления сервером. На телефоне можно использовать приложение Termius.

## 3. Установите студию

Скопируйте и выполните команду:

```
curl -fsSL https://raw.githubusercontent.com/gytfel/Tiktok/main/deploy/install.sh | sudo bash
```

Установщик сам поставит Python, ffmpeg и веб-сервер Caddy, получит бесплатный сертификат HTTPS и включит автозапуск. В конце он покажет:

```
TikTok Studio работает.

  Ссылка для телефона:  https://123.45.67.89/?key=AB3K7QXZ
  Адрес:                https://123.45.67.89
  Код доступа:          AB3K7QXZ
```

и QR-код.

## 4. Откройте студию на телефоне

Отсканируйте QR-код из терминала камерой телефона (или введите ссылку вручную). Студия откроется и запомнит вход — код вводится один раз.

**Важно:** студия на сервере — отдельная копия со своей ссылкой `https://IP-сервера/?key=…`. Студию на компьютере (`start.bat`) и кнопку **📱** в ней для этого запускать не нужно — туннель Cloudflare тут не участвует. На компьютере ту же ссылку можно открыть в браузере. Если потеряли ссылку — `sudo tiktok-studio info`.

- Добавьте студию на главный экран: Safari — «Поделиться → На экран Домой», Chrome — «⋮ → Добавить на главный экран».
- Ключи Pexels и нейросетей введите заново в **⚙ Настройках** — настройки с компьютера на сервер не переносятся.
- Если сразу после установки браузер пишет, что подключение не защищено, подождите 1–2 минуты (сертификат ещё выпускается) и обновите страницу.

## Управление

Подключитесь к серверу (`ssh root@IP`) и выполните нужную команду:

| Команда | Что делает |
|---|---|
| `sudo tiktok-studio info` | показать ссылку, код доступа и QR-код |
| `sudo tiktok-studio update` | обновить студию до последней версии (видео, загрузки и настройки сохранятся) |
| `sudo tiktok-studio restart` | перезапустить студию |
| `sudo tiktok-studio logs` | журнал работы (`logs 300` — последние 300 строк) |
| `sudo tiktok-studio status` | состояние служб |
| `sudo tiktok-studio new-key` | сменить код доступа (все телефоны войдут заново) |

После перезагрузки сервера студия запускается сама.

## Свой домен (необязательно)

Если у вас есть домен, ссылка может быть вида `https://studio.example.ru` вместо IP-адреса:

1. У регистратора домена создайте **A-запись** `studio` → IP-адрес сервера и подождите 5–30 минут.
2. Запустите установку с параметром `--domain`:

```
curl -fsSL https://raw.githubusercontent.com/gytfel/Tiktok/main/deploy/install.sh | sudo bash -s -- --domain studio.example.ru
```

Повторные обновления домен помнят — `sudo tiktok-studio update` его не сбросит.

## Безопасность

- Студией может пользоваться любой, у кого есть ссылка с кодом, — не публикуйте её. Если ссылка куда-то утекла, выполните `sudo tiktok-studio new-key`.
- После 30 неверных кодов за 10 минут вход временно закрывается — подобрать код не получится.
- Соединение шифруется (HTTPS). Студия доступна только через Caddy, напрямую порт 8765 из интернета закрыт.
- Видео, загрузки, ключи нейросетей и код доступа хранятся в `/var/lib/tiktok-studio` и доступны только служебному пользователю студии.

## Если что-то не работает

| Проблема | Что делать |
|---|---|
| В студии на компьютере пишет «Cloudflare выдал ссылку, но подключиться… не удалось» | Это туннель студии на компьютере, к серверу он не относится. Откройте на телефоне ссылку сервера из `sudo tiktok-studio info`. |
| Ссылка не открывается или долго грузится | Проверьте, что в панели провайдера открыты порты TCP 80 и 443. Затем `sudo tiktok-studio status` — обе службы (`tiktok-studio` и `caddy`) должны быть `active (running)`. |
| «Подключение не защищено» не проходит больше 5 минут | Сертификату нужны открытые порты 80 и 443. Причину покажет `sudo journalctl -u caddy -n 50`. После исправления — `sudo tiktok-studio restart`. |
| «502 Bad Gateway» | Студия перезапускается — подождите 10 секунд. Если не помогло: `sudo tiktok-studio restart` и `sudo tiktok-studio logs`. |
| Установщик пишет «на диске сервера свободно всего … МБ» | Нужно хотя бы 1,5 ГБ свободного места. Выберите тариф с диском побольше или удалите лишнее. |
| Не работает озвучка | Сервисы Microsoft бывают недоступны из некоторых стран. Укажите прокси в ⚙ Настройках или выберите сервер в другом расположении. |
| Заканчивается место на сервере | Удалите старые ролики и загрузки в студии. Свободное место: `df -h /`. |
| Забыли код доступа | `sudo tiktok-studio info` |

## Удаление

```
sudo systemctl disable --now tiktok-studio
sudo rm -rf /opt/tiktok-studio /var/lib/tiktok-studio /etc/systemd/system/tiktok-studio.service /usr/local/bin/tiktok-studio
```

Caddy останется установленным; его настройки — в `/etc/caddy/Caddyfile`.
